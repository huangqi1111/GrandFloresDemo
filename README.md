# GrandFloresDemo

Unity 制作的横版动作游戏 Demo，包含城镇探索、地下城选择、多房间战斗、角色攻击与技能、怪物行为及 BOSS 战等内容。

## 运行方法

1. 下载或克隆完整仓库。
2. 保持目录结构不变。
3. 双击 `GrandFloresDemo.exe` 运行。

`GrandFloresDemo_Data`、`MonoBleedingEdge`、`UnityPlayer.dll` 和 `UnityCrashHandler64.exe` 均为运行所需文件，请勿只复制 EXE。

## 环境

- Windows 64 位
- Unity Windows 构建版本

## 说明

这是个人学习与作品展示用 Demo，当前仍在持续完善。

## Unity 源工程

可编辑的 Unity 工程位于 `UnityProject/`，包含：

- `Assets`：脚本、场景、美术、音频与配置数据
- `Packages`：包依赖清单
- `ProjectSettings`：项目设置

推荐使用 Unity 2022.3.62f1 打开。首次导入时 Unity 会自动重建未上传的 `Library`、`Temp`、`Logs` 等缓存目录。
